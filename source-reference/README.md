# Source Reference

This portfolio repository intentionally does **not** duplicate the entire collaborative source tree.

## Original implementation

- Team repository: https://github.com/me-dangnhatminh/apie-adv-proj
- Historical working snapshot: https://github.com/me-dangnhatminh/apie-adv-proj/tree/eb124439b6e06f64396fb23db5aa6e4c7ce71c8f

The historical snapshot is the preferred source-level reference when reviewing the fuller implementation state supplied by the team.

## Why not copy every file here?

A full copy would:

- detach source files from their original collaborative commit history;
- blur individual vs team authorship;
- duplicate test/document artifacts unnecessarily;
- make the portfolio harder for recruiters to review;
- create a second codebase that can silently diverge from the original.

Instead, this repository focuses on architecture, system-design reasoning, security/privacy, operational concerns, product boundaries, and traceable links back to the original implementation.

## Portfolio policy

If selected source snippets are added later, they should be:

1. clearly attributed to the collaborative project;
2. sanitized of credentials/PII;
3. small enough to explain a technical decision;
4. linked back to the original path/commit;
5. not presented as sole-authored code unless independent evidence supports that claim.
